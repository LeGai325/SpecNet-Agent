## 1. 总结结论

本阶段已经完成一套**隔离、可复现、可证伪**的机制研究框架：上游 simulator 只读加载，所有派生代码、随机种子、配置与结果都留在 `specnet_proofs/`；完整测试套件现为 **93/93 通过**。

**本阶段最重要的正向成果**：针对原始共享动作规则中 `spec_pressure` 不可辨识的问题，完成了压力变量重定义与控制路径因子化。最终版本以 `congestion`、`slack` 和 `active_speculative_backlog` 分别驱动 admission、全局调度和 deadline 调度；三项消融在独立确认中均通过 quality、coverage、broad 和 nonjoint gate。因此，当前 RQ1 的主结论是：**重新定义后的因子化三信号机制完整支持**。原始 `spec_pressure` 的负结果保留为此次机制修复的出发点，而非当前 RQ1 的最终结论。

研究工作必须分成两条线解读：

1. **三项证明（RQ1–RQ3）**：RQ1 已得到重新定义后的三信号完整机制证据；RQ2 和 RQ3 也给出明确的可引用正、负结论。它们回答“在当前 simulator 中，哪些信息与控制机制可辨识、规则能否稳定替代学习控制、决策能否审计”，而不等于生产部署完成。
2. **三项证明以外的部署/资源工作**：已完成公平语义修复、有限 TTL、V4/V5 资源优化、V6/V7 失败诊断、质量契约及其事件模拟接入；其中只有 V4/V5 是 simulator 内较成熟的候选，V6/V7 与 Quality-Contract Broker（QCB）仍是探索性结果，尚不能宣称资源鲁棒或可部署。

下文中“完成”表示**研究问题已有可复现的肯定或否定结论**，不是指真实系统或论文全部完成。

## 4. 三项证明：完成情况

### 4.1 RQ1／证明一：重定义后的 `C`、`S`、`P` 三个状态信号均有可辨识作用

**最终主结果（应优先汇报）**：原始共享动作规则无法把三个信号的作用清楚分开；完成压力语义修复后，采用因子化三路径控制器，`C/S/P` 三项均得到独立支持。这不是简单“调出了更好数字”，而是先定位不可辨识的定义/路径问题，再以冻结参数和独立 seed 重新验证后的机制改进。

| 信号及其最终定义 | 当前结论 | 完成状态 | 可引用边界 |
|---|---|---|---|
| `C`（congestion） | 移除后高拥塞切片的 P99 latency 变差 | 已支持 | 当前 simulator 内的因子化机制 |
| `S`（slack） | 移除后紧 deadline 切片的 normalized latency 变差 | 已支持 | 当前 simulator 内的因子化机制 |
| `P`（active speculative backlog） | 移除后高推测积压下 waste 变差 | 已支持 | 仅适用于重新定义后的 factorized `P` 路径 |

- 量化结果：在 8 月 5 日的独立确认中，三个消融均呈预注册方向变差：去掉 `C` 的 broad P99 delta 为 `+29.80244`，去掉 `S` 的 broad normalized-latency delta 为 `+0.09299`，去掉 `P` 的 broad waste delta 为 `+5.25746`；三项 Holm-adjusted `p=0.00015`，并均通过 nonjoint gate。
- 已完成内容：将 `C/S/P` 分配到 source admission、全局调度、deadline 调度三条独立路径；在 synthetic 因子化确认中以 **81 场景 × 5 个独立 runs** 通过三项 broad/nonjoint gate，并在 trace-driven V3 上以 **18 场景 × 2 runs** 给出迁移确认。
- 已完成统计保障：消融只删除对应的一个变量；使用预注册方向、配对比较、场景分层 bootstrap 与 Holm 校正；候选参数和确认 seed 均冻结。
- 历史修正的意义：早期共享动作规则的 `H1-P`（original ratio）不支持，broad slack 也曾失败；这促成了对 `P` 语义及控制路径的重新设计。应如实保留该过程，但不能用早期负结果覆盖当前因子化机制的完整正结果。
- 当前结论：**重新定义后的三信号机制证明已完成且三项均支持**；尚未完成真实网络、真实任务质量、多瓶颈或多租户下的外部有效性验证。

主要工件：[因子化确认报告](specnet_proofs/results/factorized_signal_confirm_v1_20260730/FACTORIZED_SIGNAL_REPORT.md)、[trace V3 确认报告](specnet_proofs/results/trace_v3_test_v3_merged_20260806/TRACE_FACTORIZED_SIGNAL_REPORT.md)、[8 月 5 日周报](2026.8.5_第三次周报.md)。

### 4.2 RQ2／证明二：固定规则能否稳定替代 learned bandit

- 已完成内容：在相同状态输入、五种动作、quality gate 与调参预算下比较 bandit 和固定/调优规则；完成规则搜索、配对比较、source-control isolation 与 validation→test 漂移审计。
- 已完成的研究结论（负结论）：固定规则可以命中某些 operating point，但没有证据表明单一冻结规则能跨负载、deadline、optional 工作量和 trace profile 稳定支配 bandit。故**“规则可全面替代 bandit”不成立**，这一否定性回答已经完成。
- 关键新增证据：V5 的同一 validation 冻结候选在独立 V2 test 出现 `Δp99=+0.69`、`Δmiss=+0.00458`，说明 validation 最优并不稳定迁移到 test；不能用 test 再调参数。
- 当前结论：**替代性证明已完成为不支持**；“应采用何种鲁棒自适应控制器”仍未完成，后续应做 worst-group constrained selection 或 constrained contextual bandit。

主要工件：[原始三项证明 full v2](specnet_proofs/results/proof_full_v2_20260719/PROOF_REPORT.md)、[优化研究](specnet_proofs/results/optimization_full_v3_20260719/OPTIMIZATION_REPORT.md)、[validation→test 漂移审计](specnet_proofs/VALIDATION_TO_TEST_SHIFT_AUDIT_20260811.md)。

### 4.3 RQ3／证明三：策略是否可解释、可复现、跨 seed 稳定

- 已完成内容：导出 Q-table 与状态覆盖；分离 action-table agreement 和 held-out performance equivalence；完成 state/Q-table/guard 重放、单变量反事实、策略检查点、seed 与日志哈希审计。
- 已完成的研究结论：给定某次训练得到的 state、Q-table、guard 和日志，最终动作**可以审计与复现**；这是“可追溯解释”，而不是从表格本身推出因果规律。
- 未支持且已如实保留：不同 seed 的动作一致性与性能稳定性不足，单个 Q-table 不能被称为普遍稳定规律。早期证据中仅 22/27 状态达到 `N>=30`，跨 seed 动作一致率约 `0.407`，因此不能宣传“策略跨 seed 稳定”。
- 当前结论：**可审计性部分完成并支持；普遍稳定性未完成且当前不支持**。QCB 后续提供了更细的审计字段，但不改变冻结 RQ3 的统计结论。

主要工件：[证据协议说明](specnet_proofs/README.md)、[7 月 22 日周报](2026.7.22_第二次周报.md)、[QCB 审计](specnet_proofs/results/quality_contract_validation_audit_20260816/QUALITY_CONTRACT_TRACE_AUDIT.md)。

## 7. 尚未完成事项与推荐顺序

1. **冻结后独立确认 QCB。** 不能再用 V1/V2 validation 选择 tier 或预算；应固定方案后在独立 split 上一次性报告 primary/degraded/rejected 三组的 quality、P99、miss、bytes、waste 与 debt 守恒。
2. **改用 worst-group 资源门。** 以 load、deadline、optional bytes、capacity、trace profile 分组，报告 mean/P95/P99 与最差 cell，避免平均值掩盖 V5/V6/V7 的尾部回归。
3. **补齐部署边界。** 做 capacity drop、burst/arrival blackout、信号延迟、多租户与 tenant fairness；将 drain、TTL、总 bytes、每 path utilization 分位数纳入 hard gate。
4. **真实系统验证。** 接入真实 token/byte 计数、真实答案质量评测、NIC/GPU/CPU 指标和具有许可证记录的真实 trace replay；在此之前不得称端到端 QoS 或生产收益。
5. **工程化复现。** 将 simulator、policy、guard、metrics、plotting 进一步模块化，并将 smoke、schema/manifest 检查加入 CI。

## 8. 当前可用于汇报的一段话

> 本阶段已完成 SpecNet-Agent 的隔离证据链。最核心的正向成果是：发现原始 `spec_pressure` 定义和共享动作路径不可辨识后，完成了压力语义修复与因子化控制；重新定义后的 congestion、deadline slack、active speculative backlog 三个信号均在独立确认中通过 broad/nonjoint 机制检验。固定规则没有表现出跨环境稳定替代学习控制器的能力；策略在给定状态、Q 表和 guard 时可审计重放，但跨 seed 的普遍稳定性仍不成立。三项证明之外，已修复 background 公平机制的生命周期语义并完成有限 TTL、V4/V5 资源优化和 QCB/byte-debt 研究。V5 是当前最成熟的 simulator baseline；V6/V7 与 QCB 仍处于 validation-only 阶段，尚需冻结后的独立确认、最差组资源门和真实系统验证，不能写成已部署或生产最优。
