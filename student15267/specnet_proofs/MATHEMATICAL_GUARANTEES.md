# SpecNet 控制机制的数学边界

这份说明只证明“在明确假设下必然成立”的机制，不把模拟器结果包装成真实网络中的普适定理。

## 1. 符号

- `C`：关键流（planner、required branch、LLM、judge）的待发送字节量。
- `O`：可选流（speculative branch 和 background）的待发送字节量。
- `B`：一个调度时间片可提供的带宽。
- `w_i > 0`：流 `i` 的调度权重。
- `lambda_C`、`lambda_O`：关键流和可选流的平均到达字节率。
- `mu`：链路可提供的平均服务率。
- `Q`：质量；在当前模拟器中它是保留分支数量的代理，不是真实答案正确率。

## 2. 可严格证明的两个结论

### 命题 A：删除可选流不会降低同一调度器下的关键流服务

假设调度器是 work-conserving weighted max-min：只要还有流，就用满 `B`；在同一轮中，流 `i` 按 `w_i / sum_j(w_j)` 分得带宽；流完成后，剩余带宽继续分配给未完成流。假设关键流的到达、大小和权重不因删除 `O` 而改变。

则从系统中删除任意可选流集合 `O` 后，每个关键流在每个时间片获得的服务量不会下降，关键流完成时间不会变晚。

**证明。** 在没有删除前，关键流集合为 `C`，可选流集合为 `O`。若所有流都未完成，关键流 `i` 的第一轮份额为

```text
s_i = B * w_i / (sum_{k in C} w_k + sum_{j in O} w_j).
```

删除 `O` 后，第一轮份额变为

```text
s'_i = B * w_i / sum_{k in C} w_k >= s_i.
```

如果某个流在一轮中完成，删除可选流只会增加剩余带宽，不会减少已经给关键流的服务。对每个后续轮次重复同样的比较，可用归纳法得到关键流的累计服务量逐轮不减。因此达到自身字节量所需的轮数不增，完成时间不晚。`□`

这个结论支持“减少可选流量有助于保护关键路径”，但它不保证整体效用更高，因为 `Q` 可能下降。

### 命题 B：减少平均流量会降低负载率并扩大稳定范围

在单瓶颈流体近似下，系统总平均到达率为

```text
lambda = lambda_C + lambda_O,
rho = lambda / mu.
```

队列稳定的充分条件是 `rho < 1`。如果源端控制使可选流到达率从 `lambda_O` 降到 `lambda'_O <= lambda_O`，则

```text
rho' = (lambda_C + lambda'_O) / mu <= rho.
```

所以任何原来稳定的工作点仍然稳定；一些原来 `rho >= 1` 的工作点也可能因为削减可选流而回到 `rho' < 1`。

**证明。** 直接由 `lambda'_O <= lambda_O` 和 `mu > 0` 得 `rho' <= rho`；稳定条件是严格不等式 `rho' < 1`。`□`

在排队论的更细模型中，平均等待时间还取决于到达突发性、服务时间分布和调度优先级，因此这里只证明稳定域扩大，不证明固定比例的延迟改善。

## 3. 不能仅靠上述定理推出的结论

1. 不能推出 SpecNet bandit 在所有场景都优于规则。bandit 还受到状态离散、训练样本和 reward 设计影响。
2. 不能推出 H1-P 的质量约束 waste 必然下降。降低 `O` 可能减少浪费，也可能牺牲 `Q`；两者需要实验同时测量。
3. 不能把 `Q` 当成真实语义正确率。必须接入答案正确率、检索召回率或人工/模型评测后，才能讨论语义质量。
4. 不能把 oracle gap 当成在线可达收益。oracle 使用了事后信息，只能诊断状态表示或训练策略的改进空间。

## 4. 与当前代码和实验的对应关系

- 命题 A 对应 `source_control_isolation` 中固定 `critical_path` 队列、改变源端动作的比较。
- 命题 B 对应 `congestion` 使用 active remaining bytes 的设计，以及高负载下 p99/超时变差的实验现象。
- 真实实验还包含质量代理和 finite-workload 截断，因此报告中必须同时给出质量、延迟和浪费，不能只报告单一指标。

## 5. 下一步严格化

- 将 weighted max-min 分配写成与代码逐轮一致的离散引理，并用有限状态穷举验证。
- 引入多瓶颈时，把 `mu` 替换为瓶颈集合上的容量约束，检查删除可选流是否仍保持关键流单调性。
- 用真实 Agent trace 替换 `Q` 代理，验证数学结论与语义指标是否一致。
